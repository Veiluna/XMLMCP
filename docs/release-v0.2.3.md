# XMLMCP v0.2.3

使用新版已标记极片模板填充空白部分，完整保留“极片电阻仪参考资料”、原有图片和图表；母版制作取消按附录位置删除对象。报告生成与独立完整性验证均检查参考资料原字节和对象依赖，误填、误删参考资料会取消整批。

可填母版的逐点表按实际样品数和测量点数调整行列数量，每列宽度、每行高度保持不变。两个样品使用五列，五个样品使用十一列；平均值与 COV 行紧跟实际测量点。动态表格复用母版已有字体、底色、边框和数字格式，未用区域恢复原背景，表格外布局保持不变。标准空白区最多五个样品、十六个点或压强工步，超出则报错。

- 从嵌入 WMF 的选定文字字体读取中文字体、字号和字重，变压表标题及表头保留粗体。
- 新版模板中的单元格方框文字与委托单复选框状态对应；共享文字隔离，保留富文本各段字体。
- 继续生成六种真实数据统计 PNG，替换结果区的参考图框；附录图片保留。
- 继续保留中文图名、坐标轴、真实表头和缺失字段清单。
- Windows / macOS 共用源码安装包，MacBook 无需 Microsoft Excel，可在 WPS 查看离线报告。

源码包仅包含合成测试与公开说明，不包含业务模板、委托单、原始 ZIP 或真实报告。参考 PNG 图表由绘图参数重建，不承诺不同数据下逐像素相同。

安装见 [INSTALL.md](https://github.com/Veiluna/XMLMCP/blob/master/INSTALL.md)，首次映射确认与母版制作见 [报告说明](https://github.com/Veiluna/XMLMCP/blob/master/docs/report-workflow.md)。解压后运行安装脚本，导入该电脑生成的 `mcp.local.json`，启动参数保持 `["-m", "xmlmcp"]`。
