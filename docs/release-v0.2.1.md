# XMLMCP v0.2.1

生成的单点散点图、变压曲线使用中文图名和横纵轴标题。电阻率单位仍为 Ω·cm，实测压强单位仍为 MPa。

中文字体明确应用到图名、轴标题和图例；包内附带开放许可的标题字体子集，支持没有合适系统字体时的绘图，不修改系统字体。任意中文样品名仍需要系统字体覆盖其字符。

安装步骤不变：Windows 执行 `python scripts/setup.py`，Mac 执行 `bash scripts/setup.sh`，导入生成的 `mcp.local.json`。报告生成不需要 Microsoft Excel。

通过字形渲染、报告完整性和跨平台回归检查后发布。用户业务输入与生成报告不包含在公共下载包中。
