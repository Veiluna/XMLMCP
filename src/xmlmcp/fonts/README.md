# XMLMCP 中文图表标题字体

XMLMCPChartLabels.ttf 是 Noto Sans SC 的 400 字重子集，包含固定中文图名/坐标标题、ASCII、Latin-1、Ω 和负号。它作为没有合适系统字体时的备用字体，不安装到操作系统；任意中文样品名仍使用 Windows 微软雅黑或 macOS 苹方/黑体等完整字体。

原字体来自 [Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)，使用随附的 SIL Open Font License 1.1；子集改名为 XMLMCP Chart Labels，继续使用同一字体许可。

源字体 SHA-256：`a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`。生成时保留版权/许可元数据，去除其他字符和可变字重，只保留 400 字重。
